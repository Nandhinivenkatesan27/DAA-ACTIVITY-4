Description

This project consists of five programming problems implemented using Java. The main purpose of this activity is to understand programming logic and develop problem-solving skills by applying different algorithms.

The programs cover concepts such as dynamic programming, arrays, strings, and bit manipulation. Each problem focuses on a specific computational task and demonstrates how it can be solved using Java.

Problems Solved

1. Climbing Stairs (LeetCode 70)

Problem Description:

You are climbing a staircase with "n" steps. You can climb either one step or two steps at a time. The objective is to find the total number of distinct ways to reach the top.

Approach:

The program uses dynamic programming to calculate the number of possible ways to reach each step based on the previous two steps.

Example:

- Input: "3"
- Output: "3"

2. House Robber (LeetCode 198)

Problem Description:

A robber wants to rob houses arranged in a row. Each house contains a certain amount of money. The robber cannot rob two adjacent houses. The objective is to find the maximum amount of money that can be collected without robbing neighboring houses.

Approach:

The program uses dynamic programming to determine the maximum amount of money that can be collected while avoiding adjacent houses.

Example:

- Input: "[2, 7, 9, 3, 1]"
- Output: "12"

3. Coin Change (LeetCode 322)

Problem Description:

Given an array of coin denominations and a target amount, find the minimum number of coins required to make that amount. If the amount cannot be formed using the available coins, return "-1".

Approach:

The program uses dynamic programming to find the minimum number of coins needed for each amount up to the target value.

Example:

- Coins: "[1, 2, 5]"
- Amount: "11"
- Output: "3"

4. Longest Common Subsequence (LeetCode 1143)

Problem Description:

Given two strings, find the length of their longest common subsequence. A subsequence maintains the relative order of characters but does not require them to be consecutive.

Approach:

The program uses a two-dimensional dynamic programming table to compare the characters of both strings and calculate the length of the longest common subsequence.

Example:

- Text 1: "abcde"
- Text 2: "ace"
- Output: "3"

5. Number of 1 Bits (LeetCode 191)

Problem Description:

Given an integer, count the number of set bits ("1"s) in its binary representation. This is also known as the Hamming weight of the number.

Approach:

The program uses bitwise operators to examine the binary representation of the integer and count the number of bits set to one.

Example:

- Input: "11"
- Binary Representation: "1011"
- Output: "3"

Conclusion

This project provides practical experience in solving programming problems using Java. By implementing these five problems, important concepts such as dynamic programming, array processing, string manipulation, and bit manipulation are explored. This activity helps improve logical thinking, strengthen programming fundamentals, and develop the ability to solve computational problems efficiently.
